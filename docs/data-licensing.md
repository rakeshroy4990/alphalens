# Data licensing

AlphaLens must not redistribute production market data until redistribution and **end-user display** rights are confirmed in writing.

## Current environment

- Quotes, candles, and fundamentals are generated by `MockMarketDataProvider` / `MockFundamentalCatalog` and labeled `MOCK`.
- Kite is a broker adapter only. Do not treat Kite as the market-data source ([Kite FAQ](https://support.zerodha.com/category/trading-and-markets/general-kite/kite-api/articles/kite-connect-api-faqs): displaying or redistributing Kite data on external platforms violates exchange data-vending policy).
- Frontend clients must never call third-party market-data APIs.

## Phase 27 decision (not a signed contract)

Preferred vendor **intent**: TrueData (exchange-authorised). Runner-up: Global Datafeeds.

See [market-data-provider-decision.md](market-data-provider-decision.md).

Do **not** enable a production `MarketDataProvider` implementation until this file names:

- vendor legal name
- contract date
- permitted uses (display, cache, store, derive)
- user/device limits
- the backend adapter class

Until then the implementation remains `MockMarketDataProvider`.
